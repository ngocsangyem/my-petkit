Litter box 100234567 · firmware 1.2.86

Runs commands on the box as root. A mistake can stop it booting, and it is outside the warranty.

What changes on the device

Adds /system/app_init.sh, which starts the local video server at boot instead of the cloud relay. Firmware files are not overwritten.

How to undo

Undo removes that one file and reboots the box. Stock firmware starts again and the cloud relay returns.

Space on the box

Needs 1.1 of 6.8 MB free

Reachable: the server talks to the box on the home network

If the box stops answering, the reason shows here, for example no answer on port 22.

Confirm it is you

Root-level changes need your admin password. It stays valid for 5 minutes.
